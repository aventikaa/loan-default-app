# loan-default-app
# Overview

Predicts the probability of a borrower defaulting using XGBoost.

# Dataset

Lending Club loan data
Features used:
-loan amount
-interest rate
-DTI
-annual income
-grade
-etc. 
# Model
XGBoost Classifier
ROC AUC: 0.709
# Key Insights
Higher interest rates increased default probability
Lower loan grades had higher default rates
DTI strongly affected risk
